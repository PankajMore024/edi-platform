Database schema & modeling

How documents, config, and the transaction lifecycle are stored. The document model uses class-table inheritance: a shared supertype for what every doc type has, per-doc-type subtypes for what only they have, and generic child tables for the structures that recur across all doc types — no sparse columns, no per-tenant tables, one place for cross-type dashboards.
